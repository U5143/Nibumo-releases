# Nibumo

イラスト制作と Live2D の作業を手伝う、Windows 用の小さな道具です。
パーツの図を押すとレイヤー名が描画ソフトへ入り、色合わせの逆算もその場でできます。

A small Windows helper for illustration and Live2D work: click a part to paste its layer name into your
drawing app, and work out blend colours on the spot.

## このリポジトリについて / About this repository

ここは **Nibumo のアプリが自動更新に使うファイルの置き場** です。
アプリは起動したときにここを確かめ、新しい版があれば知らせます（入れるのは「更新して起動し直す」を押したときだけです）。

This repository holds the files **Nibumo uses for in-app updates**. The app checks here at startup and
tells you when a new version is available; it only installs when you press "Update and restart".
